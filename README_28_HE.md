# Kolbo Video Grid — Pilot 2.8 | וידאו + סאונד אוטומטי

**סטטוס:** ניסוי מדיה מבודד שעבר בדיקות, **לא שירות ייצור או APK חדש**.

## מה מבוצע ללא עריכה ידנית

הסקריפט בודק וידאו בן 8 שניות, מזהה פגיעות של כדור כתום בקרקע על סמך פריימים, יוצר אפקטים תואמים, משלב אותם ל-MP4 ובודק אורך, תנועה ועוצמת סאונד. כל זה עובד ב-CPU; לא דרוש GPU לעריכת הסאונד. הבדיקה המלאה הצליחה גם על סרטון LTX-2.5 המקורי שכבר נוצר בסשן קודם, ובו אותרו **11 אירועי תנועה**.

## שלושה מצבי שימוש

- `fixture`: וידאו דמה סינתטי מקומי כדי להוכיח תזמור, בדיקות ועריכת סאונד אוטומטית **ללא יצירת AI**.
- `existing`: מקבל קובץ וידאו קיים שנוצר בעבר ומפיק ממנו MP4 מסונכרן, עם דוח QA. ניתן לשימוש רק לסצנת כדור כתום על רקע דשא.
- `live`: בקשה אחת לדוגמת LTX-2.5 הציבורית באמצעות Hugging Face, **רק** לאחר העברת הדגל `--allow-external-synthetic-upload`. במצב זה נשלחת תמונה *סינתטית בלבד*, לא תמונת משתמש. אין הבטחת קיבולת או מכסה, ואין עקיפת הגבלות שימוש. אין הפעלה אוטומטית של הבדיקה הזו.

## הפעלה

להתקין FFmpeg, FFprobe ודרישות Python מקובץ `requirements-pilot.txt`. מתוך תיקיית החבילה:

```bash
python -m pilots.kolbo_grid_28_pilot --mode fixture --duration 8 --out demo
python -m pilots.kolbo_grid_28_pilot --mode existing --duration 8 --source-video previous-video.mp4 --out repaired
# ניסוי ענן אופציונלי אך ורק עם תמונה סינתטית:
python -m pilots.kolbo_grid_28_pilot --mode live --duration 8 --allow-external-synthetic-upload --out remote-test
```

הקובץ יופיע בשם `kolbo-pilot.mp4` ודוח הבקרה בשם `report.json`. אם אחד התנאים אינו מתקיים, המצב הוא `BLOCKED` או `QA_FAILED` ולא `PASS`.

## מה עדיין חסר

1. אין מנוע שמבטיח ביצוע סמנטי של כל הוראה בעברית, שמירת דמות, דיבור ותנועת שפתיים.
2. אין בדיקת כתוביות אוטומטית אמינה; `subtitle_absence_verified=false`.
3. הסאונד הוא אפקטים פרוצדורליים של כדור כתום, **לא** הסאונד המקורי מהמודל ולא תחליף לסאונד של אנשים או סצנות אחרות.
4. Render Free נותר ב-read-only; אין שינוי בשירות הפעיל או אחסון קבוע.
5. שימוש ב-LTX-2.5 ציבורי תלוי במכסתו וברישיונו; אין GPU חינמי בלתי מוגבל.
6. הקובץ הזה הוא רכיב ניסיוני שאפשר לשלב בעתיד ב-Worker ייעודי, אבל **לא פורסם כשרת HTTPS ציבורי ולא שולב באפליקציה**.

## בטיחות ופרטיות

לעולם אל תשתמש במצב live עם תמונות פרטיות, תמונות משתמשים או מפתחות API בתוך הבדיקה הזו. קבצי העבודה נשארים מקומיים למעט תמונת הבדיקה הסינתטית כאשר ניתן אישור מפורש בדגל. GitHub Actions יכול לשמש לבדיקות CI בלבד, לא כשרת GPU פרטי מתמשך.

## בקרת עמידה בפעולה — תוספת 2.8

נוספה בדיקה שמנסה לזהות לפחות שתי קפיצות נראות של כדור כתום לפני יצירת אפקטי פגיעה. זו בדיקה המבוססת על שינויי כיוון אנכיים של האובייקט, ולכן היא **מוגבלת לסצנת הכדור**, לא הבנה סמנטית של כל סוג וידאו. אם המנוע מחזיר סרטון שבו הכדור רק מחליק או זז ללא קפיצה נראית, הזרימה נעצרת עם `BOUNCE_ACTION_NOT_VERIFIED` ואינה מייצרת צלילי פגיעה בדויים.

בניסוי LTX-2.5 החדש מאותו יום התקבל MP4 אמיתי של 8 שניות, אבל נצפו 0 קפיצות אנכיות מתאימות — לכן ההפקה לא עברה את בקרת הפעולה. זהו **כשל במילוי ההוראה הוויזואלית**, לא בהכרח בעיית תקשורת או מכסה. קובץ הווידאו הגולמי נשמר לניתוח, בלי להציגו כהפקה גמורה.

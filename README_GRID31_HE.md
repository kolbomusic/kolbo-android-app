# Kolbo Video Grid 3.1 — ממשק תיקון ניסיוני מאובטח

**המצב:** קוד שנבדק מקומית. *לא נפרס לשרת Render הפעיל ולא חובר ל־Android APK.* זהו שלב נוסף בתשתית, ולא מערכת ליצירת סרטוני AI כלליים.

## מה עובד

- `POST /v1/repair/scoped-ball` — מקבל וידאו בן 8 שניות של **כדור כתום יחיד ברקע דשא יציב, מצלמה קבועה**, לאחר אישור מפורש לשינוי התנועה.
- מבצע עיבוד CPU של הסרטון שהועלה, כולל קומפוזיציה של שתי קפיצות והפקת שני צלילי נחיתה פרוצדורליים, ובודק בדיוק 2 קפיצות, משך 8 שניות, אודיו והיעדר התכהות חריגה.
- מחזיר ZIP שמכיל `repaired.mp4` וגם `report.json`. הדוח מפרט שהתנועה נערכה ושאין כאן הפקת וידאו AI חדשה או אודיו AI מקורי; אינו מאשר סמנטיקה, פנים, שפתיים או כתוביות.
- `GET /v1/repair/scoped-ball/status` — יכולות וזמינות ללא חשיפת מפתח או פרטי תשתית.
- וידאו המקור **אינו נדרס**; קובצי עבודה נמחקים לאחר השלמת ההורדה.

## אבטחה ותנאי הפעלה

הרכיב חסום כברירת מחדל. נדרשים במפורש *כל* התנאים הבאים **בשרת ניסוי מבודד בלבד**:

- `KOLBO_REPAIR_API_ONLY=1` — חוסם בקשות כתיבה ישנות שאינן במסלול התיקון.
- `KOLBO_SCOPED_REPAIR_ENABLED=1` — מאפשר את נתיב התיקון המסוים בלבד.
- `KOLBO_GRID_DEMO_READONLY=0` — רק בשרת פרטי/מבודד המאושר לכך; בשרת הציבורי Render הקיים ערך זה נשאר `1`.
- `KOLBO_CLOUD_API_KEY` — סוד חזק שנקבע בשרת בלבד, מועבר ללקוח פרטי בערוץ מוגן. **אין להטמיע אותו ב־APK שמופץ לציבור**.

בקשת POST מחייבת את כותרת `X-API-Key`, ואת שדות הטופס:

`scene_profile=orange_ball_meadow_static_camera`

`duration=8`

`exact_bounces=2`

`explicit_consent=RECOMPOSE_BALL_MOTION_AND_REPLACE_AUDIO`

`file`: קובץ AVI/MP4 נתמך, עד 15MiB.

יש מגבלת פעולה אחת בכל רגע. שירות זה משתמש בבקשת HTTP ארוכה **ללא תור משימות מתמיד**, ולכן אינו עמיד לכיבוי/ניתוק טלפון ואינו תחליף לתשתית 24/7. אין להעלות תוכן אישי לפני השלמת ביקורת אבטחה ופרטיות נוספת. אין להפעיל ב־Render Free במצב ציבורי עם כתיבה ואחסון זמני.

## בדיקות

```bash
python -m pip install -r requirements.txt
# ffmpeg and ffprobe must be available on PATH
PYTHONPATH=. python -m unittest discover -s tests -v
```

גרסה זו העבירה 17 בדיקות מקומיות ב־10 באוקטובר 2026, כולל תהליך API מקצה לקצה עם סרטון AI קיים (שהוכן במסגרת ניסוי קודם), הרשאות, הגבלת העלאות, סירוב ללא הסכמה ונתיבים חסומים. דוח הענן ניתן לאימות בנפרד ב־GitHub Actions.

## Docker

`docker build -t kolbo-grid:3.1 .`

הרצת Docker בברירת מחדל היא **לקריאה בלבד** (ללא כתיבה). אפשר להפעיל תיקון **רק** בסביבת ניסוי מבודדת עם משתני הסביבה שלעיל ואישור מפורש של בעל השירות. לא בוצעה פריסה בפועל.

## הגבלות איכות

הפרופיל מבוסס על איתור אובייקט כתום לפי צבע וצורה ועל רקע יציב, לא על מודל הבנת וידאו כללי. הוא ישנה במפורש את התנועה המקורית ולכן לעולם לא ישווק כהפקת AI נטו. דמויות אנושיות, נופים משתנים, מצלמה נעה, דיבור וכתוביות אינם נתמכים ונדרשים מנגנוני עיבוד ואימות נפרדים.

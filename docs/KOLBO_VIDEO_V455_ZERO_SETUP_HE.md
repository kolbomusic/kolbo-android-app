# Kolbo Video 4.5.5 — Android ללא הגדרה ידנית

## מה כבר עובד ב-APK
- פתיחת ממשק Android מקורי בעברית, בלי כתובת שרת או הרשמה לשירות GPU חיצוני
- בקשה בעברית (תיאור הסרטון), בחירת עד שתי תמונות עם הרשאות מקומיות של Android
- משך סרטון מבוקש 1–15 שניות, שירה/דיבור כאפשרות
- שמירת טיוטה פרטית באחסון האפליקציה ושחזור בעת פתיחה מחדש
- בדיקה אוטומטית ולא חסומה של GET /v1/app-config בשרת Kolbo המוגדר בקוד
- **ללא שליחת תמונות או תיאור לשרת** לפני הפעלת אחסון, אימות ומשאב GPU אמיתיים
- אין חיוב אוטומטי או בקשות לשירותים חיצוניים

## מצב ההפקה — לא מוכנה
האפליקציה משתמשת כרגע בכתובת הקבועה
https://kolbo-video-v450-safe-preview.onrender.com/v1/app-config
שהיא **תשתית בדיקה בלבד**. לכן פעולת 'צור את הסרטון שלי'
שומרת בקשה מקומית ומדווחת שעדיין אין הפקת AI פעילה.
אין מצג שווא על יצירת סרטון, על GPU זמין או על שמירת פנים.

## חסרים לקראת הפקה מלאה
1. שרת HTTPS פרטי שמחובר ל-Neon PostgreSQL ולאחסון מדיה private S3, עם סודיות ואימות מוכחים
2. כניסת משתמש מאובטחת ללא הזנת כתובת שרת — למשל התחברות OAuth עם PKCE (לא למזג בלי בדיקות)
3. עובד GPU אמיתי שמחזיק הרשאה ומודל וידאו/אודיו, ואומת באמצעות הרצת ניסיון
4. חוזה העברת מדיה מאובטח מהאפליקציה והחזרת MP4 עם בדיקות איכות/זהות
5. בדיקה על טלפון Android פיזי, כולל שמירת סרטון וניגונו
6. משאב מחשוב שנתרם/ממומן בהסכמה; אין כיום משאב GPU בלתי מוגבל בחינם באופן מובטח

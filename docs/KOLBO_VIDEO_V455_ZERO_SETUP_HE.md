# Kolbo Video 4.5.5 — אולפן Android ללא הגדרה ידנית

**מה בוצע**
- נבנה מסך Native בעברית עם תיאור סצנה, בחירת 0–2 תמונות, משך 5/10/15 שניות ושמירת טיוטת ההנחיה באופן מקומי (האפליקציה *אינה* שומרת את התמונות עצמן כטיוטה).
- הוסרו שדה כתובת HTTPS וקישורי מנועי Hugging Face; אין להזין או לבחור ספק.
- כתובת בדיקת המוכנות נכללת ביישום ונבדקת אוטומטית דרך HTTPS ללא redirect.
- **אפס העברות תמונה** אל שרת ה־preview.
- התנאי לפתיחת אולפן הפקה מוגן ב-10 תנאים, כולל `mobile_session_auth_ready`. כדי להתקדם בעתיד נדרש backend שיודע לאמת סשן משתמש מתוך האפליקציה, **בלי הזנת אסימון בעלים**.
- בדיקות CI: קומפילציית Android + בדיקת תנאים שליליים + היעדר הגדרות ידניות וקישורים לספקי GPU חיצוניים.
- האפליקציה אינה מתקינה מודלי AI בטלפון ואינה צורכת ממנו GPU משמעותי.

**מה לא בוצע**
- השרת הקיים בכתובת `https://kolbo-video-v450-safe-preview.onrender.com` הוא `preview_only`. משום כך כפתור ההפקה יישאר **חסום**, והמסך יציג סיבה מפורשת.
- אין עדיין פריסת production mesh, חיבור אוטומטי מאובטח בין Neon ל־Render, עובד GPU שנתרם בהסכמה, או הוכחה מעשית ל־15 שניות עם שירה, lip-sync ושתי דמויות.
- אין הקצאת GPU אינסופית; תורים אפשר להשאיר ללא הגבלה יומית באפליקציה, אך זמני העיבוד תלויים ביכולות וזמינות תורמים.

**למה שמירת הטיוטה אינה יצירה**
התיאור והמשך נשמרים בהעדפות הפרטיות של האפליקציה. תמונות שנבחרו מוחזקות זמנית במכשיר ורק מספרן מוצג; אינן עוברות לשרת. כשמנוע ההפקה יהיה מוכן, יהיה צורך במנגנון מסירה מונחה־אימות של התמונות וההנחיה; לחיצה על Create תיכנס לאולפן המאומת (לא תרנדר לבד). לא מוצג 'סרטון הצלחה' לפני יצירת מדיה אמיתית ואישור QA.

**שער שחרור מוצר**
לפני שחרור כ'מוצר מלא' נדרש backend עם `mobile_session_auth_ready`, מסד ואחסון קבוע, GPU מורשה, בדיקת יצירת סרטון מקצה לקצה ובדיקת זהות/קולות/משמעות. אסור להפוך את הדגלים ל־true ללא ראיות.

**התקנה**
ה־APK הוא Debug ונחתם במפתח פיתוח אוטומטי של GitHub Actions, לא חתימת Release. התקנה על הטלפון עשויה להתנגש עם גרסאות Debug שנחתמו בסביבה אחרת. אין לעקוף הגנות Android; במקרה של התנגשות חתימה יש לשמר נתונים לפני הסרת גרסה ישנה.

# הקרנפים | ברקן — קהילת יוצאי פלוגה ב׳

Hebrew RTL reunion portal. PostgreSQL via Neon; Render deploy; accounts require administrator approval. No Google OAuth until dedicated Google OAuth client configuration, redirect URI, and verification. Set SECRET_KEY, DATABASE_URL, ADMIN_EMAIL privately. The admin must register and be approved by setting approved=true securely in DB. Do not publish private details or contact information without member opt-in.

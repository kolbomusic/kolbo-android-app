# אתר הקרנפים / ברקן — קהילת יוצאי פלוגה ב׳

אתר Flask בעברית RTL, מסד נתונים PostgreSQL ב־Neon ואירוח ב־Render. אתר קהילתי עצמאי (לא אתר רשמי של צה״ל).

## חברות, אימות דוא״ל, כניסה ותוכן

- **אין Google Sign-In, OAuth או Google Identity Services** באפליקציה. הוסרו מודול ההתחברות וכל בדיקותיו. אימות הבעלות של Google Search Console הוא נפרד וחיוני להסרת אזהרת הדפדפן.
- **חשבונות קיימים:** גיבובי סיסמאות PBKDF2-SHA256 נשמרים ללא איפוס. חשבונות שנוצרו לפני אימות הדוא״ל החדש אינם מסומנים בטעות כמאומתים בדיעבד, והם אינם חסומים בגלל דרישת אימות שמיועדת רק לנרשמים חדשים.
- **נרשמים חדשים:** טופס הרשמה יוצר חשבון עם verification_required=true. נשלח קישור אימות חד־פעמי בתוקף 24 שעות. פתיחת GET אינה צורכת את האסימון (מגינה מפני סורקי קישורים במייל); נדרש אישור POST עם CSRF. אסימון נשמר כגיבוב בלבד, ונמחק בעת אישור. עד האימות אין התחברות.
- **לאחר אימות:** אפשר להתחבר בסיסמה אישית, להעלות עד ארבעה קבצים (תמונה, סרטון קצר, קול) ולשלוח סיפורים/אירועים, ולראות את הפרסומים הפרטיים באזור ״הפרסומים שלי״. **אישור חברוּת וביקורת התוכן הם שלב נפרד**, ורק פרסומים מאושרים נחשפים לשאר חברי הקהילה.
- **אין חובה להעביר תוכן ל־Google Gemini:** בדיקת AI היא אופציונלית בהסכמה מפורשת; בלי סימון נשמר התוכן פרטי לביקורת מנהל, ו־ai_consent=false נשמר במסד.

## דוא״ל באירוח חינמי

Render Free חוסם תעבורת SMTP יוצאת בפורטים 25, 465 ו־587, לכן השירות משתמש ב־HTTPS API ולא ב־SMTP.

כדי להפעיל אימות דוא״ל אמיתי יש להגדיר ב־Render שני משתני סביבה (בלי לשים סודות בקוד):
- `KARNAFIM_RESEND_API_KEY` — מפתח של ספק הדוא״ל Resend עם מכסת חינם. אין לחייב מנוי בתשלום.
- `KARNAFIM_MAIL_FROM` — כתובת שולח בדומיין שבבעלות מפעיל האתר ואומת אצל Resend (למשל `קהילת הקרנפים <community@kolbomusic.com>`, רק לאחר אימות הדומיין וההרשאה).
- הטמעת מפתח API/אימות דומיין אינם מבוצעים אוטומטית ללא חשבון שירות דוא״ל והרשאות. אם אין הגדרה, GET /register מחזיר 503 ולא אוסף פרטי חברים שאין דרך לאמתם.

## תנאי פתיחת הקהילה

האתר **כרגע במצב קריאה בלבד**, כדי למנוע חשיפת נתונים בזמן ש־Google Safe Browsing מסמנת את כתובת האתר כ־Deceptive pages. אין לעקוף את אזהרת הדפדפן. לאחר הסרת הסיווג ועם מעבר בדיקות האבטחה, הגדר:
- `KARNAFIM_MAINTENANCE=0`
- `KARNAFIM_SAFETY_RELEASE_APPROVED=1`
- `KARNAFIM_LOCAL_AUTH_ENABLED=1`
- `KARNAFIM_ALLOW_REGISTRATION=1` **רק אחרי** חיבור מערכת המיילים.

אם אחד משלושת התנאים הראשונים חסר, האתר לא יפתח את מסד החברים, דפי הסיסמה, האזור האישי או ההעלאות. כל עוד אזהרת Google פעילה, אין להפעיל את התנאים.
